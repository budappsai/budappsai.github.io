Un dossier prêt à l'emploi, sans installateur : on le décompresse et on lance L'Atelier.

Télécharger pour Windows

Une licence est nécessaire. Elle vous est envoyée par courriel après l'abonnement (voir les tarifs). Sans licence, L'Atelier s'installe mais ne s'ouvre pas : pour découvrir avant d'acheter, parcourez la démo guidée.

Sur Mac

  1. Ouvrez le fichier téléchargé, puis glissez L'Atelier sur le dossier Applications.
  2. Lancez-le depuis Applications. La première fois, si macOS refuse de l'ouvrir : Réglages Système › Confidentialité et sécurité, puis « Ouvrir quand même ».
  3. Collez votre licence : c'est prêt.
  4. Mise à jour : L'Atelier vous prévient au démarrage. Fermez sa fenêtre, téléchargez, et glissez par-dessus en acceptant de remplacer. Vos dossiers ne bougent pas.

Sur Windows

  1. Faites un clic droit sur le fichier téléchargé › Extraire tout.
  2. Ouvrez le dossier ATELIER et lancez ATELIER.exe. Si Windows affiche « Windows a protégé votre ordinateur » : « Informations complémentaires », puis « Exécuter quand même ».
  3. Collez votre licence : c'est prêt.
  4. Mise à jour : L'Atelier vous prévient au démarrage. Fermez-le, téléchargez, et remplacez l'ancien dossier par le nouveau. Vos dossiers ne bougent pas.

Les fichiers sont hébergés sur GitHub, dans le dépôt public de BudappsAI, qui ne contient aucun code source. En téléchargeant, vous acceptez les conditions générales.
