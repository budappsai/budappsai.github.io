Télécharger pour Windows

Une licence, ou un code d'accès, est nécessaire pour télécharger comme pour ouvrir PROJETLIA. La licence vous est envoyée par courriel après l'abonnement (voir les tarifs). Pour découvrir le logiciel avant de l'acheter, parcourez la démo guidée.

Sur Mac

  1. Ouvrez le fichier téléchargé, puis glissez PROJETLIA sur le dossier Applications.
  2. Lancez-le depuis Applications. Si macOS refuse de l'ouvrir la première fois : Réglages Système › Confidentialité et sécurité, puis « Ouvrir quand même ».
  3. Collez votre licence ou votre code d'accès : PROJETLIA est prêt.
  4. Mise à jour : PROJETLIA vous prévient au démarrage. Fermez sa fenêtre, téléchargez la nouvelle version et glissez-la sur l'ancienne en acceptant de la remplacer. Vos dossiers sont conservés.

Sur Windows

  1. Faites un clic droit sur le fichier téléchargé › Extraire tout.
  2. Ouvrez le dossier PROJETLIA et lancez PROJETLIA.exe. Si Windows affiche « Windows a protégé votre ordinateur » : « Informations complémentaires », puis « Exécuter quand même ».
  3. Collez votre licence ou votre code d'accès : PROJETLIA est prêt.
  4. Mise à jour : PROJETLIA vous prévient au démarrage. Fermez-le, téléchargez la nouvelle version et remplacez l'ancien dossier par le nouveau. Vos dossiers sont conservés.

Avant la version 1.28.0, PROJETLIA s'appelait ATELIER : si l'ancienne application est encore installée, vous pouvez la supprimer ; vos dossiers sont conservés.

Les fichiers sont fournis par le serveur de BudappsAI, hébergé par Cloudflare, sans lien public : chaque lien reste valable une heure. En téléchargeant, vous acceptez les conditions générales.
